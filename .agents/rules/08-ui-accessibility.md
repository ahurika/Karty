Purpose

Define UI, responsive, and accessibility constraints.

Rules
UI-001 — Responsive First

The shop must work on:

Mobile
Tablet
Desktop
UI-002 — No Required Horizontal Scrolling

Core shopping and checkout functionality must not require horizontal scrolling on normal viewport sizes.

UI-003 — Keyboard Access

Interactive controls must be keyboard accessible.

UI-004 — Visible Focus

Interactive controls must have a visible focus state.

UI-005 — Form Labels

Form controls must have accessible labels.

UI-006 — Validation Feedback

Validation errors must be understandable and accessible.

UI-007 — Do Not Use Color Alone

Do not communicate important information using color alone.

UI-008 — Meaningful Images

Meaningful product images must have appropriate alternative text.

Decorative images should not create unnecessary screen-reader noise.

UI-009 — Touch Targets

Interactive controls must remain usable on touch devices.

UI-010 — Preserve Checkout Usability

Do not prioritize visual styling over the ability to complete checkout.

UI-011 — Loading States

Long-running operations such as:

Authentication
Checkout
Payment initialization

must provide an appropriate loading state and prevent accidental duplicate submissions.

UI-012 — Error States

Every important asynchronous UI operation must have a usable error state.
